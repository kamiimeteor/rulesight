# Starter rules

Copy the rules you want into `~/.claude/CLAUDE.md` (every project) or a `CLAUDE.md` in your project folder, and change the wording to match how you work. Rulesight checks each list item as one rule. A paragraph like this one is not checked, so keep every rule on its own line that starts with `-`.

## Before you start

- When my request is unclear, ask me one question before you start.
- Before you write code, tell me in a few sentences what you plan to do, and wait for my reply.

## Files

- Ask me before you delete, move, or rename any file.
- Do not change files outside this project folder.

## Checking your work

- After you change code, run the tests and tell me the result in plain words.
- Do not tell me something works unless you ran it and saw it work.
- If a step fails, tell me what failed. Do not skip it quietly.

## When something blocks you

- If a command is blocked or refused, stop and ask me. Do not try another command that does the same thing.

## Talking to me

- Reply in the language I write in.
- Avoid jargon. When you need a technical term, explain it in one line.

## Anything that leaves this computer

- Ask me before you push, publish, deploy, or send anything.
- Ask me before you install anything outside this project.
